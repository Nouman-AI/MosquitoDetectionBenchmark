# Trained Deep Learning Model Weights

This directory provides information about the trained deep-learning model checkpoints associated with the Mosquito Detection Benchmark.

The ten trained model checkpoints are publicly archived on Zenodo.

**Zenodo DOI:** https://doi.org/10.5281/zenodo.24021658

## YOLO Models

- YOLO11n
- YOLO11s
- YOLOv8n
- YOLOv8s

## TorchVision Models

- Faster R-CNN ResNet50-FPN-V2
- Faster R-CNN MobileNetV3-Large-FPN
- Mask R-CNN ResNet50-FPN-V2
- RetinaNet ResNet50-FPN-V2
- SSD300-VGG16
- SSDLite320-MobileNetV3-Large

The archive contains the selected checkpoints for the ten deep-learning detectors evaluated in the study. The associated model configurations, hyperparameter settings, and reference implementations are provided in the main GitHub repository.
